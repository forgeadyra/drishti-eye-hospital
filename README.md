# Drishti Eye Hospital — website

A static, prerendered marketing site with a 3D animated hero and one serverless function for the
contact form.

**Stack:**
- Vite 8, React 19, TypeScript (strict) and Tailwind CSS v4.
- three.js via @react-three/fiber and drei.
- GSAP with ScrollTrigger and SplitText for scroll motion, Framer Motion for UI micro-interactions, and Lenis for smooth scrolling.
- One Netlify Function for the contact form: zod, Cloudflare Turnstile, Upstash rate limiting and Resend email.

**Live:** https://drishti-eye-hospital.netlify.app

- lint;
- typecheck;
- the full build, including every `verify-dist` gate;

## Quick start

```bash
npm ci
npm run dev        # http://localhost:5173 (no prerender, no CSP; for editing)
npm run build      # production build + all build gates
npm run preview    # http://localhost:4173, serves dist/ with the exact production headers
```

Requires Node ≥ 22 to build; Node ≥ 23.6 to run `npm run test:contact` (it imports the TypeScript function directly). CI uses Node 24.

## Editing content

| What | Where |
|---|---|
| All business facts (phone, address, hours, services, about text, facts, socials) | `src/content/business.ts` |
| Gallery photos | drop JPG/PNG/WebP into `assets-src/images/` **and** add alt text for each file to `assets-src/images/alt.json` (`{ "reception.jpg": "Reception desk at Drishti Eye Hospital" }`). The build fails if alt text is missing. |
| Colours / fonts | `src/styles/index.css` (`@theme`) |
| Motion timing / easing | `src/motion/config.ts` (single source for GSAP + Framer Motion) |
| Security headers / CSP | `config/headers.ts` |

**Placeholders.** Any value written as `{{LIKE_THIS}}` is highlighted in gold on the page and left out of JSON-LD and meta tags. The build prints a `NOTICE` listing whatever is still a placeholder.

**Rules for content.** Never add reviews, ratings, prices, patient numbers or success rates unless the hospital supplies them and can stand behind them.

Images are converted to AVIF and WebP at 480, 960 and 1600 px with `srcset` and explicit dimensions. The hero poster, favicons and OG image are generated by `scripts/optimize-images.mjs`, which runs automatically on every build.

## Environment variables

Copy `.env.example` → `.env` for local function testing. **Never commit `.env`** (it's gitignored).

| Variable | Where | Secret? | Purpose |
|---|---|---|---|
| `VITE_TURNSTILE_SITE_KEY` | Netlify env (build) | No, public by design | Turnstile widget site key. Falls back to Cloudflare's test key if unset. |
| `TURNSTILE_SECRET_KEY` | Netlify env (functions) | **Yes** | Server-side Turnstile verification |
| `UPSTASH_REDIS_REST_URL` | Netlify env (functions) | **Yes** | Rate limiting store |
| `UPSTASH_REDIS_REST_TOKEN` | Netlify env (functions) | **Yes** | Rate limiting store |
| `RESEND_API_KEY` | Netlify env (functions) | **Yes** | Sends the enquiry email |
| `CONTACT_TO_EMAIL` | Netlify env (functions) | No | Where enquiries are delivered |
| `CONTACT_FROM_EMAIL` | Netlify env (functions) | No | Sender, on a domain verified in Resend |
| `ALLOWED_ORIGIN` | Netlify env (functions) | No | Exact production origin for CORS, e.g. `https://www.example.com` |

> Anything prefixed `VITE_` is compiled into public JavaScript. Never give a secret a `VITE_` name.

In production the function **fails closed**: if any required secret is missing, it returns a generic 500 rather than skipping a check.

## Deploy (Netlify)

1. **Create the accounts** (free tiers are enough):
   - **Cloudflare Turnstile.** Add a widget for your domain, plus `*.netlify.app` if you use deploy previews. Copy the site key and secret key.
   - **Upstash.** Create a Redis database and copy its REST URL and REST token.
   - **Resend.** Verify your sending domain, create an API key, and choose the from/to addresses.
2. **Push this repo** to GitHub, GitLab or Bitbucket.
3. **Netlify → Add new site → Import from Git.** The build settings come from `netlify.toml` (`npm run build`, publish `dist`, functions `netlify/functions`).
4. **Site settings → Environment variables:** add every variable in the table above. Scope the secrets to **Functions**, and `VITE_TURNSTILE_SITE_KEY` to **Builds**.
5. **Deploy**, then verify the preview deploy:
   ```bash
   curl -I https://<deploy-preview-url>/
   ```
   ```bash
   node scripts/test-ratelimit.mjs https://<deploy-preview-url>
   ```
   ```bash
   npm run lighthouse -- https://<deploy-preview-url>/
   ```
6. **Add your custom domain.** Set `ALLOWED_ORIGIN` to it exactly, with no trailing slash, and redeploy.
7. **HSTS preload.** The site already sends `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`. Only submit the domain at hstspreload.org once **every** subdomain serves HTTPS, because preloading is hard to undo.

Netlify sets the `URL` env var at build time, and it's used for the canonical URL, Open Graph URLs, `sitemap.xml`, `robots.txt` and JSON-LD. Override it with `SITE_URL` if needed.

## Scripts

| Command | What it does |
|---|---|
| `npm run build` | images → `tsc -b` → client build → SSR build → prerender (+ inline CSS with CSP hash, deferred boot) → `verify-dist` gates |
| `npm run lint` | ESLint, zero warnings allowed (includes jsx-a11y strict, `no-console`, `target="_blank"` guard) |
| `npm run typecheck` | TypeScript project build |
| `npm run test:contact` | 34 security tests for the contact function (needs internet for Turnstile siteverify) |
| `npm run qa:browser` | Headless Chrome QA vs `npm run preview`: 3D, reduced motion, no-WebGL, low-end, 360/768/1440, menu a11y, CSP violations |
| `npm run lighthouse` | 3 mobile Lighthouse runs vs preview, checks the budget |
| `npm run check:deps` | depcheck |
| `npm run audit` | `npm audit --audit-level=high` |
| `ANALYZE=1 npx vite build` | bundle breakdown → `stats.json` |

`netlify-cli` isn't a dependency, because its dependency tree carries high-severity advisories. Use it on demand:

```bash
npx netlify-cli@27.12.0 dev --offline --dir dist --functions netlify/functions
```

## How the performance budget is met

- **Prerendered HTML.** The h1, copy and CTAs are in the initial HTML, and the critical CSS is inlined under a CSP sha256 hash. The app JS is fetched after first paint by `boot-*.js`.
- **Initial JS** is about 165 KB gzipped (budget 250 KB). The 3D scene (three.js) is a separate lazy chunk, and it is never downloaded under reduced motion, without WebGL, on low-end devices (≤ 4 cores / ≤ 4 GB / Save-Data), or before the visitor interacts.
- **The 3D scene** renders on demand (`frameloop="demand"`). It pauses when off-screen or when the tab is hidden, and DPR is capped at 1.5. It's fully procedural: 0 KB of models or textures.
- **Fonts** are self-hosted (Fraunces + Inter, variable, latin subsets, `font-display: swap`), with metric-matched fallbacks so the swap causes no layout shift.

## Continuous deployment

The live site was created with the Netlify connector as a manual deploy. To redeploy on every push, go to Netlify, then **Project configuration → Build & deploy → Continuous deployment → Link repository**, and pick this GitHub repo. The build settings come from `netlify.toml`.
